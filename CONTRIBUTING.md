# Contributing to DotNetDeployNotify

Thank you for contributing! Please follow these guidelines:

1. **Reporting Issues:** Use GitHub Issues for bugs or features.
2. **Security:** Do not open public issues for security vulnerabilities; see [SECURITY.md](SECURITY.md).
3. **Pull Requests:** 
   - Fork the repository and create a feature branch.
   - Target the `main` branch.
   - Include tests for new features/fixes.
   - Ensure CI passes.
   - Keep commits logical and atomic.
4. **Code Style:** 
   - Follow existing conventions.
   - Use XML documentation for public members.
   - Include author headers.
5. **License:** All contributions are licensed under the MIT License.

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for behavior expectations.
