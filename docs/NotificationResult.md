# NotificationResult

`NotificationResult` represents the outcome of a single delivery attempt for a notification within the `dotnet-deploy-notify` system. It tracks the status, metadata, and response details of the attempt, including success, failure, retry scheduling, or skipping. This type is used to persist and analyze the delivery lifecycle of notifications across various channels.

## API

### `public string Id`
A unique identifier for this delivery attempt result. Typically generated by the persistence layer.

### `public string NotificationId`
The identifier of the notification associated with this delivery attempt.

### `public NotificationChannel Channel`
The communication channel through which the notification was attempted (e.g., Email, SMS, Webhook). Defined by the `NotificationChannel` enum.

### `public string ConfigurationId`
The identifier of the channel-specific configuration used for this delivery attempt.

### `public DeliveryStatus Status`
The current delivery status of the attempt. Possible values include `Pending`, `Sent`, `Failed`, `Retrying`, `Skipped`, or `Timeout`.

### `public int? HttpStatusCode`
The HTTP status code returned by the remote endpoint, if applicable. `null` if the attempt did not involve an HTTP request or if no response was received.

### `public string ResponseBody`
The raw response body received from the remote endpoint, if applicable. Empty if no response was received or if the attempt did not involve an HTTP request.

### `public string? ErrorMessage`
A human-readable error message describing the failure, if applicable. `null` if the attempt was successful or not yet attempted.

### `public string? ExceptionType`
The fully qualified type name of the exception that caused the failure, if applicable. `null` if no exception occurred.

### `public int AttemptNumber`
The sequential number of this attempt (e.g., `1` for the first attempt, `2` for the first retry).

### `public long DurationMs`
The duration of the attempt in milliseconds, measured from initiation to completion or failure.

### `public DateTime AttemptedAt`
The UTC timestamp when the attempt was initiated.

### `public DateTime? LastRetryAt`
The UTC timestamp of the last retry attempt, if applicable. `null` if no retries have occurred.

### `public DateTime? NextRetryAt`
The UTC timestamp when the next retry is scheduled, if applicable. `null` if no further retries are scheduled.

### `public bool IsValid`
Indicates whether the result is in a valid state for processing. This may be `false` if required fields are missing or if the result is corrupted.

### `public void MarkAsSuccessful()`
Marks the attempt as successfully delivered. Updates the `Status` to `Sent` and clears any retry-related fields. Does not throw.

### `public void MarkAsFailed()`
Marks the attempt as failed. Updates the `Status` to `Failed` and clears any retry-related fields. Does not throw.

### `public void MarkForRetry()`
Marks the attempt for retry. Updates the `Status` to `Retrying` and sets `NextRetryAt` based on the configured retry policy. Does not throw.

### `public void MarkAsSkipped()`
Marks the attempt as skipped. Updates the `Status` to `Skipped` and clears any retry-related fields. Does not throw.

### `public void MarkAsTimeout()`
Marks the attempt as timed out. Updates the `Status` to `Timeout` and clears any retry-related fields. Does not throw.
